## 通过 SSH 连接到你的 VPS

服务器开通并拿到登录邮件后，就可以连进去了。从 Windows 上，装一个像 Bitvise SSH Client 这样的 SSH 客户端；在 macOS 或 Linux 上，自带的 Terminal 就行。命令如下：

bash
ssh root@你的.服务器.IP


当提示输入密码时，从登录邮件中粘贴 root 密码。一个容易让人卡住的点：很多 SSH 客户端在粘贴密码时不会显示任何内容——连星号都没有。这不是坏了。直接粘贴，按回车即可。

一旦进入，你就是一个新安装的 Linux 机器的 root 用户。更新软件包、安装你的软件、配置防火墙、部署你的应用。盒子的掌控权在你手里。

第一次登录后值得马上做的一个习惯动作是：

1. 用 `apt update && apt upgrade -y`（Ubuntu/Debian）或 `dnf update -y`（AlmaLinux/Rocky）更新所有软件包。
2. 禁用 root 密码登录，切换到 SSH 密钥认证——这是加固新 VPS 最有意义的五分钟操作。
3. 用 `ufw` 或 `firewalld` 配置一个基本的防火墙，只开启你真正需要的端口。

如果你从未做过这些，在搜索引擎里搜索“initial server setup Ubuntu 22.04”，找一份带有步骤说明的指南。这不在本教程的范围之内，但这是你接下来的正确一步。
